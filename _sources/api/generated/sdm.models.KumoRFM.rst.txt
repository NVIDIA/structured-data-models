Capabilities

   * - **Supported Input Feature Semantic Types**

   * - **Related Table Support**
     - ✅

Default Recipe
--------------

.. code-block:: python

   Recipe(
     features=Sequential(
       StypeDispatch(
         datetime: AddCalendarFields([
           'minute',
           'hour',
           'weekday',
           'day_of_month',
           'month',
         ]),
       ),
       StypeDispatch(
         categorical: Sequential(
           AlignCategories(sort_by='frequency'),
           ToNumerical(),
         ),
       ),
       StypeDispatch(
         numerical: Sequential(
           ImputeMean(),
           DropConstantColumns(),
           Standardize(),
           Clip(min_value=-100.0, max_value=100.0),
           Choice(
             Identity(),
             PowerTransform(),
           ),
           ClipSigma(),
           ShuffleColumns(),
         ),
       ),
     ),
     target=Sequential(
       StypeDispatch(
         numerical: Standardize(),
         categorical: Sequential(
           AlignCategories(sort_by='code'),
           ShuffleCategories(),
         ),
       ),
     ),
     output=Sequential(
       ReduceEstimators(method='mean'),
       TaskDispatch(
         classification: Softmax(),
         regression: Identity(),
       ),
     ),
   )
