Default Recipe
--------------


.. warning::
    Each estimator uses at most 500 columns. For wide tables, some
    columns may remain unused across the ensemble.
    Use at least ``ceil(num_columns / 500)`` estimators to make full
    coverage possible.

.. code-block:: python

   Recipe(
     features=Sequential(
       StypeDispatch(
         categorical=Sequential(
           AlignCategories(min_frequency=2),
           ToNumerical(),
         ),
       ),
       StypeDispatch(
         numerical=Sequential(
           ImputeMean(),
           DropConstantColumns(),
           Standardize(eps=1e-06),
           Clip(-100.0, 100.0),
           Choice(
             Identity(),
             PowerTransform(),
             method='round_robin',
           ),
           ClipSigma(threshold=4.0, method='log'),
           ShuffleColumns(method='random'),
           SelectColumns(max_columns=500),
         ),
       ),
     ),
     target=StypeDispatch(
       numerical=Standardize(),
       categorical=Sequential(
         AlignCategories(sort_by='value'),
         ShuffleCategories(method='shift'),
       ),
     ),
     output=Sequential(
       AverageEstimators(),
       TaskDispatch(
         classification=Softmax(temperature=0.9),
       ),
     ),
   )
