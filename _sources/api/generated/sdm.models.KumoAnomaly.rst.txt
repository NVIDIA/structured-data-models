Capabilities
------------

.. list-table::

   * - **Supported Input Semantic Types**
     - ``numerical``







Model Details
-------------

.. list-table::


   * - **Output**
     - Reconstruction scores named ``"mae"`` and boolean anomaly labels named ``"scs"`` and ``"macs"`` per time step

   * - **Missing Values**
     - Mean imputation in the default recipe

   * - **Pretraining Scope**
     - Up to 40 columns



Default Recipe
--------------




.. code-block:: python

   Recipe(
     features=StypeDispatch(
       numerical=Sequential(
         ImputeMean(),
         PCA(num_components=40),
         MinMaxScale(),
       ),
     ),
     target=Identity(),
     output=Identity(),
   )
