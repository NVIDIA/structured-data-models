Model Details
-------------

.. list-table::


   * - **Classification Output**
     - Class probabilities; ECOC for more than 10 classes

   * - **Regression Output**
     - 999 quantiles named ``"q001"`` through ``"q999"``

   * - **Missing Values**
     - Handled natively

   * - **Pretraining Scope**
     - Up to 60,000 rows and 100 columns



Default Recipe
--------------


.. warning::
    Each estimator uses at most 500 columns. For wide tables, some
    columns may remain unused across the ensemble.
    Use at least ``ceil(num_columns / 500)`` estimators to make full
    coverage possible.

.. code-block:: python

   Recipe(
     features=Sequential(
       StypeDispatch(
         numerical=Sequential(
           Cast(torch.float64),
           DropConstantColumns(),
           Standardize(eps=1e-06),
           Clip(-100.0, 100.0),
           Choice(
             Identity(),
             PowerTransform(),
             Sequential(
               RobustScale(quantile_range=(25.0, 75.0)),
               Clip(-3.0, 3.0, method='saturate'),
             ),
             RankGaussian(max_knots=8192),
             method='round_robin',
           ),
           ClipSigma(threshold=4.0, method='log'),
           FlipSign(probability=0.5),
         ),
         categorical=Sequential(
           AlignCategories(sort_by='value'),
           AddCategoryCounts(min_cardinality=50),
           ToNumerical(),
           Cast(torch.float64),
           DropConstantColumns(),
           Standardize(eps=1e-06),
           Clip(-100.0, 100.0),
           Choice(
             Identity(),
             PowerTransform(),
             Sequential(
               RobustScale(quantile_range=(25.0, 75.0)),
               Clip(-3.0, 3.0, method='saturate'),
             ),
             RankGaussian(max_knots=8192),
             method='round_robin',
           ),
           ClipSigma(threshold=4.0, method='log'),
         ),
       ),
       ShuffleColumns(method='latin'),
       SelectColumns(max_columns=500),
       Cast(torch.float32),
     ),
     target=Sequential(
       StypeDispatch(
         numerical=Sequential(
           Standardize(),
           FlipSign(probability=0.5),
         ),
         categorical=Sequential(
           AlignCategories(sort_by='value'),
           ShuffleCategories(method='shift'),
         ),
       ),
     ),
     output=TaskDispatch(
       classification=Sequential(
         AverageEstimators(),
         Softmax(),
       ),
       regression=Sequential(
         SortQuantiles(),
         AverageEstimators(trim_fraction=0.2),
       ),
     ),
   )
