Model Details
-------------

.. list-table::


   * - **Output**
     - 9 quantiles per target and time step named ``"{target}__q10"`` through ``"{target}__q90"``

   * - **Missing Values**
     - Interpolation in the default recipe

   * - **Pretraining Scope**
     - Up to 15,360 rows and 32 columns



Default Recipe
--------------




.. code-block:: python

   Recipe(
     features=Sequential(
       Interpolate(fill_leading=False),
       Detrend(threshold=0.5),
       Clip(-1e+20, 1e+20),
       Choice(
         Identity(),
         FlipSign(probability=1.0),
         method='round_robin',
       ),
     ),
     target=Sequential(
       Interpolate(fill_leading=False),
       Detrend(threshold=0.5),
       Clip(-1e+20, 1e+20),
       Choice(
         Identity(),
         FlipSign(probability=1.0),
         method='round_robin',
       ),
     ),
     output=Sequential(
       SortQuantiles(num_quantiles=9),
       AverageEstimators(),
       ClipNonnegative(),
     ),
   )
