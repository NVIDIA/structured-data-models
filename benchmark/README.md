# Benchmarks

This folder contains runnable benchmark integrations for `structured-data-models`:

- [**`tabular/`**](tabular/): Tabular benchmarks, including [TabArena and BeyondArena](https://tabarena.ai) and [TALENT](https://github.com/LAMDA-Tabular/TALENT)
- [**`relational/`**](relational/): Relational benchmarks built on [RelBench](https://relbench.stanford.edu)

The modules in this folder are repository tooling and are not included in the `structured-data-models` package.
