# Examples

* [`tabiclv2/`](tabiclv2/): Examples of `sdm.models.TabICLv2`
* [`kumorfm/`](kumorfm/): Examples of `sdm.models.KumoRFM`

Check [`tabiclv2/quickstart.py`](tabiclv2/quickstart.py) for a minimal runnable example of `TabICLv2`.
