# Examples

This folder contains runnable examples and the TALENT benchmark integration for `structured-data-models`:

- [**`tabiclv2/`**](tabiclv2/): `sdm.models.TabICLv2`
- [**`kumo/relational/`**](kumo/relational/): `sdm.models.KumoRelational`
- [**`talent/`**](talent/): [TALENT](https://github.com/LAMDA-Tabular/TALENT) integration of `structured-data-models`

See [`tabiclv2/quickstart.py`](tabiclv2/quickstart.py) for a minimal runnable `structured-data-models` example with `TabICLv2`.

The TabArena and BeyondArena integrations live under [`benchmark/tabular/`](../benchmark/tabular/).
