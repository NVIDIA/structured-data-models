StandardScale¶

class sdm.processing.StandardScale(*, with_mean: bool = True, with_std: bool = True, epsilon: float = 0.0)¶

Bases: Processor, InvertibleMixin

Center and scale each feature column.

Constant columns use a unit scale to keep the transform finite and invertible.

Parameters:

  • with_mean (bool) – If True, center each column by its fitted mean.

  • with_std (bool) – If True, scale each column by its fitted standard deviation.

  • epsilon (float) – Value added to each fitted standard deviation. The default preserves exact constant-column handling.
