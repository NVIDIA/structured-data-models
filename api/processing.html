sdm.processing#

Processor API#

Processor

Fittable, table-in/table-out transform.

InvertibleMixin

Adds inverse_transform to a Processor.

Recipe

Processing contract around an external model boundary.

Common Processors#

Identity

Return inputs unchanged.

Sequential

Apply processors and stateless callables in sequence.

Choice

Delegate to one option drawn uniformly at random.

StypeDispatch

Apply separate processor pipelines to columns grouped by semantic type.

TaskDispatch

Route model output by the transformed target's semantic type.

FeaturePermute

Permute the numerical feature columns.

ToNumerical

Move categorical columns into the numerical block.

Numerical Processors#

Clip

Clamp numerical values to a fixed interval.

QuantileClip

Clamp feature columns to fitted quantile bounds.

SigmaClip

Two-stage z-score outlier clipping with soft logarithmic bounds.

MeanImpute

Replace NaN feature values with fitted per-column means.

Power

Apply a feature-wise Yeo-Johnson power transform.

Quantile

Map feature columns through their empirical quantiles.

StandardScale

Center and scale each feature column.

ConstantFilter

Remove non-informative numerical columns learned during fit.

Categorical Processors#

CategoricalAlign

Align categorical codes to vocabularies fitted on training rows.

CategoricalImpute

Replace missing categorical values with fitted per-column values.

CategoryShuffle

Independently permute the integer codes of categorical columns.

Datetime Processors#

EncodeDatetime

Separate timestamps into numerical calendar features.

Post-Processors#

EnsembleReduce

Reduce the leading ensemble dimension of model outputs.

SoftmaxTemperature

Apply softmax to logits after temperature scaling.
