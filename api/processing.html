sdm.processing¶

sdm.processing.Processor

Fittable, tensor-in/tensor-out transform.

sdm.processing.InvertibleMixin

Adds inverse_transform to a Processor.

sdm.processing.Sequential

Apply a number of Processor instances in sequence.

sdm.processing.Clip

Clamp feature columns to fitted quantile bounds.

sdm.processing.Identity

Return inputs unchanged.

sdm.processing.MeanImpute

Replace missing feature values with fitted per-column means.

sdm.processing.Power

Apply a feature-wise Yeo-Johnson power transform.

sdm.processing.Quantile

Map feature columns through their empirical quantiles.

sdm.processing.SigmaClip

Two-stage z-score outlier clipping with soft logarithmic bounds.

sdm.processing.SoftmaxTemperature

Apply softmax to logits after temperature scaling.

sdm.processing.StandardScale

Center and scale each feature column.

sdm.processing.Recipe

Processing contract around an external model boundary.
