EnsembleTable#

class sdm.EnsembleTable(groups: Sequence[TableTensor], locations: Sequence[tuple[int, int]])#

Store and group input tables for an ensemble.

Each ensemble member is associated with one table. Shared tables are stored only once. Compatible tables are stacked along a leading dimension and form a group, so processors can process them together. Incompatible tables remain in separate groups.

Use table() to access a member’s table. Iterate over the EnsembleTable to process its groups, and replace_groups() to build an ensemble table from the processed groups.

import torch
from sdm import EnsembleTable, TableTensor

estimator_table1 = TableTensor.from_tensor(
    tensor=torch.tensor([[1.0], [2.0]]),
    columns=("value",),
)
estimator_table2 = TableTensor.from_tensor(
    tensor=torch.tensor([[-1.0], [1.0]]),
    columns=("value",),
)
estimator_table3 = TableTensor.from_tensor(
    tensor=torch.tensor([[10.0], [20.0]]),
    columns=("selected_value",),
)

ensemble = EnsembleTable.from_tables(
    tables=(estimator_table1, estimator_table2, estimator_table3),
    member_table_ids=(0, 1, 2, 0),
)

# Access tables in member order.
assert ensemble.num_members == 4
assert ensemble.table(0).equal(estimator_table1)
assert ensemble.table(3).equal(estimator_table1)

# Iterate over two groups of compatible tables.
groups = tuple(ensemble)
assert len(groups) == 2
assert groups[0].size() == (2, 2, 1)
assert groups[1].size() == (1, 2, 1)
Parameters:

  • groups (Sequence[TableTensor]) – Sequence of TableTensor, optionally stacked along their leading dimension.

  • locations (Sequence[tuple[int, int]]) – (group, batch) location of each ensemble member.
